# 资产发现与种子管理

<!-- Scope: 自由跳 SRC 与资产队列。Priority: L2。Owns: 种子、清洗、回灌和续挖。Does Not Own: 站内漏洞矩阵。 -->

自由跳必须落盘 `资产/种子队列.md`，每条记录 `seed`、`priority`、`status`（pending/doing/done/cold）、来源和备注。业务名、SRC 范围、全资 1-4 级主体、根域和已确认优质业务簇根域都可入队，数量不设上限；参股主体默认不入队。

严格执行一种子闭环：

```text
取一个种子 → 只搜索该种子 → 去重/去废/去非存活/范围闸
→ 清洗后的存活面全部进站处理 → 标记该种子 done
→ 才取下一条 pending
```

登录墙和 401/403 是存活信号，不等于放弃；停放页、超时、无业务响应才标记 cold。优质 host 立即向上归约为业务簇根域并回灌队列，但当前种子剩余存活面未处理完前不得搜索回灌词。FOFA 限流时停止空刷，只处理已入库资产和 JS/证书带出的新 host。

续挖先读取 `state/`、`covered_hosts`、队列和报告目录，跳过 done/cold/covered，从 pending 开始。FOFA 条数、探活计数和重复确认不算进度。
