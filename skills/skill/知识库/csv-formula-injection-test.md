# CSV / Spreadsheet 导出安全（2026）

> status: mixed  
> last_reviewed: 2026-09

CSV 公式注入不是默认高价值问题，但企业报表、工单、财务和通讯录导出仍应考虑电子表格应用对单元格内容的解释方式。

## 审查重点

- 用户可控文本导出到 CSV/XLSX 时是否按目标格式进行安全编码；
- 文本字段是否可能被电子表格程序解释为公式；
- 导出模板是否明确区分文本、数字、日期和公式列；
- Excel、LibreOffice、Google Sheets 等客户端行为差异是否被业务接受；
- 自动导入/二次处理流水线是否把导出文件当可信数据。

## 判断原则

仅出现以特殊字符开头的文本不直接等同漏洞。应结合真实导出流程、打开方式、目标用户和后续数据处理判断影响。

## 防御建议

- 优先使用明确类型的 XLSX writer，而不是手工拼 CSV；
- 对纯文本列强制文本类型或采用与目标客户端兼容的安全转义；
- 导出前后保持 schema 与字段类型一致；
- 对跨系统自动导入采用独立校验，不信任上一系统生成的文件。
